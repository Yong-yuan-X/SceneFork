# SceneFork

[English](./README.md)

SceneFork 是一个开源的 AI 互动叙事工作台，可将一句创意展开为适合视频生成的故事片段与分支方向。

## 当前状态

阶段 A 已实现为本地 Vue 3 Mock 体验，包含：

- 创意输入与 Mock 故事生成；
- 当前片段的视频提示词编辑；
- 提交中、排队中、生成中、保存中、成功、失败及结果未知状态；
- 手动重试与重复提交保护；
- 四个固定方向和自定义续写；
- 本地任务持久化与刷新恢复；
- 明确标注的 Mock 播放器，以及禁用的导出占位入口。

本阶段不会请求 Qwen 或 Wan。真实模型 API、服务端持久化和媒体下载属于阶段 B。

## 环境要求

- Node.js 20 或更新版本
- npm 10 或更新版本

## 安装与启动

```bash
npm install
npm run dev
```

打开 `http://localhost:5173`。

生产构建验证：

```bash
npm run typecheck
npm run build
```

## 体验 Mock 流程

1. 在右侧输入框写下故事创意。
2. 查看或编辑生成片段的视频提示词。
3. 点击“生成 Mock 视频”，观察任务状态依次变化。
4. 选择四个方向之一，或输入自定义续写方向。
5. 打开设置，可让下一次任务演示成功、失败或提交结果未知。
6. 在任务进行中刷新页面，可验证恢复同一个本地任务。

Mock 状态保存在浏览器 `localStorage` 中。可在设置中点击“清空本地演示”，或点击 SceneFork 标识重新开始。

## 环境变量

仅在需要配置时将 `.env.example` 复制为 `.env`。阶段 A 不使用任何密钥。`DASHSCOPE_API_KEY` 等变量为后续服务端预留，不得通过 `VITE_*` 暴露，也不得提交真实密钥。

阶段 B 接入模型后可能产生 API 费用；当前仓库不会发起任何付费请求。
